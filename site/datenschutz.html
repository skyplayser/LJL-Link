Das Programm LJL Link

LJL Link läuft auf dem Mac des DJs und arbeitet nur im lokalen Netzwerk. Es hat kein Konto, keine Cloud, keine Telemetrie und keine Update-Suche; es baut keine Verbindung ins Internet auf. Es sendet an das Programm LJ Link in der Lichtbooth des Clubs, nicht an uns. Für die Verarbeitung dort ist der Betreiber dieses LJ Link verantwortlich.

  • An LJ Link gehen: der Name des Macs (wie in den Systemeinstellungen eingetragen), die Version von LJL Link und der Hinweis „Serato DJ Pro“, der Club-Schlüssel aus der Datei club.json (zur Anmeldung), je Deck die Länge, BPM, Tonart, Waveforms in drei Bändern und die laufende Position sowie eine zufällige Kennung pro Track (nie der Dateipfad).
  • Tracknamen: Titel und Artist gehen nur an LJ Link, wenn der DJ es erlaubt. LJL Link fragt beim Start; die Einstellung lässt sich jederzeit umschalten. Ohne Erlaubnis verlassen Titel, Artists und Dateinamen den Mac nicht. Dateinamen, Ordner und der Ton selbst werden nie gesendet.
  • Was LJL Link liest: das Protokoll, das Serato DJ Pro während des Laufens schreibt (welche Datei auf welchem Deck liegt), die Tags und den Ton der geladenen Datei (nur auf dem Mac, für BPM, Tonart und Waveform) und die Zeitanzeige im Serato-Fenster.
  • Bildschirmaufnahme: Mit dieser macOS-Erlaubnis liest LJL Link nur kleine Ausschnitte mit Seratos Zeitanzeige und erkennt darin die Zeit. Das Bild wird weder gespeichert noch gesendet; gesendet wird nur die Zeit. Ohne die Erlaubnis läuft LJL Link ohne mitlaufende Position.
  • Lokales Netzwerk: LJL Link sucht LJ Link per Bonjour im lokalen Netzwerk, falls sich die Adresse in club.json geändert hat.

Suite-Chat im Programm

LJL Link enthält einen Chat (Alpha) mit allen Programmen der Suite im selben lokalen Netzwerk (LJ Link, VJ-Link, LJL Link), ohne Server. Er ist eingeschaltet, sobald das Programm läuft, und lässt sich im Programm abschalten; dann sendet und empfängt LJL Link keine Chat-Daten. Wenn er an ist, gehen per Multicast an alle Suite-Programme in diesem Netzwerk: dass das Programm im Raum ist, der Programmname, eine zufällige Kennung pro Start, der von dir eingegebene Name und die Position (z. B. „DJ-Pult“) und deine Nachrichten mit Uhrzeit. Neu hinzukommende Programme bekommen auf Nachfrage die zuletzt geschriebenen Nachrichten (bis zu 20 je Programm). Nachrichten werden nur im Arbeitsspeicher der laufenden Programme gehalten; LJL Link schreibt sie nie in eine Datei, nie ins Protokoll und nie in einen Fehlerbericht. Nachrichten mit dem EMERGENCY-Knopf erscheinen bei allen als Fenster unten rechts. Wer im selben Netzwerk ein Suite-Programm startet, kann den Chat lesen – schreib also nichts Vertrauliches hinein. Die Spezifikation steht öffentlich bei LJ Link.

Fehler melden oder Wunsch äußern (Programm)

In LJL Link kannst du einen Bericht erstellen. Er enthält deine Beschreibung, freiwillig eine Bewertung von 1 bis 5 Sternen und – wenn du „Diagnosedaten anhängen“ angehakt lässt – Diagnosedaten: Versionen von LJL Link, macOS und Serato, Mac-Modell, Ablageort der App (mit „~“ statt deines Benutzerordners), Club-Name, Adressen und Port aus club.json, den Zustand der Verbindung zu LJ Link, je Deck Länge, Position, BPM und Tonart, eine Zusammenfassung des Chats ohne Inhalte und die letzten Protokollzeilen. Er enthält keine Tracktitel, keine Artists, keine Dateinamen, keinen Club-Schlüssel und keine Chat-Nachrichten. Du siehst den Bericht vor dem Senden. Er wird nur übertragen, wenn du ihn selbst abschickst: per E-Mail an fehlermelden@nextphilm.de (dann erhalten wir ihn und deine E-Mail-Adresse). Du kannst ihn auch als Datei sichern oder kopieren. Wir nutzen die Daten nur zur Fehlersuche und zur Weiterentwicklung des Programms (Art. 6 Abs. 1 lit. f DSGVO) und löschen E-Mails spätestens 12 Monate nach Erledigung.

Privacy

This website uses no cookies, tracking or analytics. It is hosted on GitHub Pages; GitHub processes technically necessary access data such as your IP address. The LJ Link and VJ-Link logos on the home page are loaded from their websites, also on GitHub Pages. To show the current version, your browser asks the public GitHub API (api.github.com), which also receives your IP address; we receive nothing. Your language choice is stored only in your browser.

The LJL Link program works only in the local network: no account, no cloud, no telemetry, no update check, no internet connection. It sends to the LJ Link program in the club's lighting booth, not to us; whoever runs that LJ Link is responsible for the processing there. Sent to LJ Link: the Mac's name (as set in System Settings), the LJL Link version and “Serato DJ Pro”, the club key from club.json (to log in), and per deck the length, BPM, key, three-band waveforms, the running position and a random id per track (never the file path). Title and artist are sent only if the DJ allows it (asked at the start, can be switched any time); file names, folders and the audio itself are never sent. LJL Link reads Serato DJ Pro's log, the tags and audio of the loaded file (on the Mac only) and, with the macOS “Screen Recording” permission, small crops of Serato's time display; the picture is never stored or sent, only the time. It finds LJ Link with Bonjour in the local network.

Suite chat (alpha, on by default, can be switched off): while on, presence, program name, a random id per start, the name and position you enter and your messages with their time go by multicast to every suite program in the local network (LJ Link, VJ-Link, LJL Link); newcomers get the latest messages on request (up to 20 per program). Messages are kept only in the memory of the running programs, never written to a file, a log or a problem report. EMERGENCY messages appear as a window at the bottom right for everyone. Anyone who starts a suite program in the same network can read the chat, so do not write anything confidential.

Reporting a problem from the program creates a report you see before sending: your text, an optional rating and, if ticked, diagnostic data (versions of LJL Link, macOS and Serato, Mac model, app location with “~” for your home folder, club name, addresses and port from club.json, the connection state, per deck length, position, BPM and key, a chat summary without content and the last log lines; no titles, artists, file names, club key or chat messages). It is sent only when you send it yourself by email to fehlermelden@nextphilm.de; you can also save or copy it. Emails and contact requests are deleted at the latest 12 months after they are settled. GitHub issues are public; GitHub's privacy statement applies. We run the Discord server “NEXTPHILM” for LJ Link, VJ-Link and LJL Link; Discord Inc. (USA) processes your data there under its own privacy policy; we see your username, roles and messages there. The LJ Link Bot on that server is described in the LJ Link privacy policy. How long GitHub keeps access data is up to GitHub. Controller: Philipp Spruck, NEXTPHILM, address and email as above. You have the rights under Art. 15–21 GDPR and may complain to a supervisory authority.
